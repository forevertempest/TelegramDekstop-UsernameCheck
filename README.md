# tg-checker

Чекер доступности юзернеймов через окно **Telegram Desktop** (Windows).  
Не использует `api_id` / `api_hash`, MTProto-сессии и сторонние клиенты: ввод передается напрямую в дескриптор окна через `Win32 PostMessage`, статус считывается из дерева `UI Automation` (`pywinauto`).

---

## Принцип работы

1. **Префильтрация списка** — удаление дубликатов, пустых строк, комментариев (`#`), префиксов `https://t.me/` и `@`. Проверка формата по правилам Telegram: длина `5..32` символа, латиница/цифры/`_`, начинается с буквы, не заканчивается на `_`, без двойных `__`.
2. **Ввод без перехвата фокуса ОС** - поиск процесса `Telegram.exe` и контрола `Ui::UsernameInput` (`@username`), отправка `WM_KEYDOWN` / `WM_CHAR` напрямую в `HWND` окна. Курсор мыши и буфер обмена не затрагиваются.
3. **Чтение ответа из UIA** - опрос текстовых элементов окна (поддерживаются русский и английский языки интерфейса) и определение статуса:
   - `FREE` - юзернейм свободен (сразу дописывается в `free.txt`)
   - `TAKEN` - юзернейм занят
   - `FRAGMENT` - выставлен на аукцион Fragment
   - `INVALID` - отклонен форматом Telegram
   - `RATE_LIMIT` - временный лимит запросов
   - `UNKNOWN` - ответ не появился в пределах `RESULT_TIMEOUT`

## Запуск готовой сборки (`.exe`)

Для работы на чистой системе без установленного Python используйте скомпилированный файл из раздела **Releases** (или `dist/TelegramUsernameChecker.exe`):

1. Поместите `TelegramUsernameChecker.exe` в отдельную папку и запустите его. Файл `usernames.txt` создастся автоматически.
2. В **Telegram Desktop** откройте любое диалоговое окно с полем проверки `@username`:
   - `Настройки - Мой аккаунт - Имя пользователя` (`Settings - My Account - Username`), или
   - Настройки публичной ссылки канала/группы (`t.me/...`).
   - *Окно должно оставаться открытым (не свернутым в трей), но может находиться на заднем плане.*
3. В меню программы выберите `[3]` для добавления списка в `usernames.txt`, затем `[1]` для запуска проверки.

## Запуск из исходного кода

Требования: **Windows 10/11**, **Python 3.10+**.

```powershell
git clone https://github.com/forevertempest/TelegramDekstop-UsernameCheck.git
cd TelegramDekstop-UsernameCheck
pip install -r requirements.txt

# Интерактивный режим
python checker.py

# Прямой запуск проверки без меню
python checker.py --auto
```

## Конфигурация таймингов

Значения настраиваются через пункт меню `[4]` или в классе `Config` внутри `checker.py`:

| Параметр | По умолчанию | Назначение |
| :--- | :---: | :--- |
| `input_file` | `"usernames.txt"` | Путь к файлу со списком юзернеймов |
| `result_timeout` | `0.30` | Таймаут ожидания ответа от Telegram (сек) |
| `poll_interval` | `0.19` | Интервал опроса текстовых контролов окна (сек) |
| `min_result_delay` | `0.19` | Минимальная задержка после ввода перед чтением статуса (сек) |
| `clear_status_timeout` | `0.22` | Таймаут исчезновения предыдущего статуса после очистки поля (сек) |
| `after_clear_delay` | `0.15` | Пауза после очистки поля перед вводом следующего имени (сек) |
| `between_usernames` | `0.15` | Задержка между итерациями проверки (сек) |
| `retries` | `0` | Количество повторных попыток при получении статуса `UNKNOWN` |
